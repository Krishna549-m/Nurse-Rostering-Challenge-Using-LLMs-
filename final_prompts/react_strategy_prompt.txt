INRC-II CONSTRAINT GUIDE

Hard constraints:
1. minimal_coverage
   Meaning: every day, shift, and skill must satisfy minimum required coverage.
   This must never become positive.
   If this becomes positive after a move, the move is invalid.

2. required_skill
   Meaning: every assigned nurse must be qualified for the assigned skill.
   This must never become positive.
   If this becomes positive after a move, the move is invalid.

3. illegal_succession
   Meaning: forbidden shift successions are violated, including historical boundary from the previous planning period.
   This must never become positive.
   If this becomes positive after a move, the move is invalid.

4. single_assignment
   Meaning: a nurse has more than one assignment on the same day.
   This must never become positive.
   If this becomes positive after a move, the move is invalid.

Soft penalties:
1. optimal_coverage_cost
   Meaning: staffing is below optimal coverage, but still above minimum coverage.
   Useful neighborhoods:
   - coverage_fill
   - reassign
   - swap
   Avoid removing assignments if this cost is high.

2. total_assignment_cost
   Meaning: nurses are below minimum total assignments or above maximum total assignments.
   Useful neighborhoods:
   - reassign
   - swap
   - block_reassign
   Avoid coverage_fill if many nurses are already above max_total.

3. consecutive_cost
   Meaning: minimum/maximum consecutive assignments, consecutive shift-type assignments, or consecutive days off are violated.
   Historical boundary matters.
   Useful neighborhoods:
   - swap
   - reassign
   - block_swap
   - block_reassign

4. non_working_days_cost
   Meaning: consecutive days off constraints are violated.
   Useful neighborhoods:
   - swap
   - reassign
   - block_swap

5. preferences_cost
   Meaning: nurse is assigned to an undesired shift/day.
   Preferences are shift-OFF requests:
   - shift = Any means the nurse prefers not to work any shift that day
   - shift = specific shift means the nurse prefers not to work that shift
   Useful neighborhoods:
   - swap
   - reassign

6. max_working_weekend_cost
   Meaning: nurse works more weekends than allowed.
   Useful neighborhoods:
   - swap
   - block_swap
   - block_reassign

7. complete_weekends_cost
   Meaning: nurse works exactly one of Saturday/Sunday when complete weekend is required.
   Useful neighborhoods:
   - swap
   - block_swap
   - block_reassign

Neighborhood meanings:
1. reassign
   Python moves one assignment from one nurse to another nurse on the same day.
   Best for:
   - total assignment imbalance
   - preferences
   - workload redistribution
   - some consecutive violations

2. swap
   Python swaps assignments/off-days between two nurses on the same day.
   Best for:
   - preferences
   - consecutive violations
   - weekend violations
   - preserving coverage

3. coverage_fill
   Python adds an assignment to a free qualified nurse for a day/shift/skill with optimal coverage shortage.
   Best for:
   - optimal_coverage_cost
   Risk:
   - may increase total_assignment_cost
   - may increase consecutive_cost
   - may increase max_working_weekend_cost

4. block_reassign
   Python moves multiple assignments from one nurse to another across several days.
   Best for:
   - repeated penalties involving the same nurse
   - total assignment imbalance
   - max weekend violations
   Risk:
   - may create new consecutive violations for destination nurse

5. block_swap
   Python swaps assignments/off-days between two nurses across several days.
   Best for:
   - repeated consecutive penalties
   - repeated weekend penalties
   - preference clusters
   - preserving total assignment counts better than block_reassign

6. mixed
   Python generates candidates from all neighborhoods.
   Best when:
   - recent attempts failed
   - no single penalty dominates
   - search is stuck

Decision rules:
- Never choose a strategy that is likely to create hard violations.
- If hard violations appear in recent observations, choose neighborhoods that restore hard feasibility.
- If optimal_coverage_cost dominates, choose coverage_fill unless recent coverage_fill increased total cost.
- If consecutive_cost dominates, choose swap, block_swap, or block_reassign.
- If preferences_cost dominates, choose swap or reassign.
- If total_assignment_cost dominates, choose reassign or block_reassign.
- If max_working_weekend_cost or complete_weekends_cost dominates, choose block_swap or block_reassign.
- If the same neighborhood failed repeatedly, choose mixed.
- Choose stop only if recent attempts show no useful improvement direction.
